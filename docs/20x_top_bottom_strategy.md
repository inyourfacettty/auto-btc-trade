# BTC-USDT 20x 摸顶摸底策略

更新时间：2026-05-28  
适用市场：OKX BTC-USDT / BTC-USDT-SWAP  
策略类型：4小时级别高胜率反转策略  
执行周期：4H确认信号，下一根15m开盘执行

## 1. 策略定位

这套策略不是追趋势，也不是频繁短线。它只做两类机会：

- 价格打到阶段低位后，出现明显下影线反转，做多。
- 价格打到阶段高位后，出现明显上影线反转，做空。

核心思想：

```text
位置极端 + RSI极端 + 长影线反打 + 收盘确认
```

它追求的是高胜率，而不是单笔大盈亏比。回测中胜率较高，是因为止盈很短、止损较宽，所以必须严格等待信号，不能凭感觉提前进。

## 4. 做多条件

全部满足才允许做多：

```text
1. 当前4H最低价接近唐奇安60下轨，上浮不超过 0.5%
2. RSI14 <= 35
3. 当前4H是阳线，即收盘价 > 开盘价
4. 当前4H收盘价 > 上一根4H收盘价
5. 当前4H下影线 >= 整根K线振幅的 50%
6. ATR14 / 当前4H收盘价 在 0.6% 到 6% 之间
7. 等4H收盘确认后，下一根15m开盘做多
```

下影线比例计算：

```text
整根K线振幅 = 最高价 - 最低价
下影线长度 = min(开盘价, 收盘价) - 最低价
下影线比例 = 下影线长度 / 整根K线振幅
```

## 5. 做空条件

全部满足才允许做空：

```text
1. 当前4H最高价接近唐奇安60上轨，下浮不超过 0.5%
2. RSI14 >= 65
3. 当前4H是阴线，即收盘价 < 开盘价
4. 当前4H收盘价 < 上一根4H收盘价
5. 当前4H上影线 >= 整根K线振幅的 50%
6. ATR14 / 当前4H收盘价 在 0.6% 到 6% 之间
7. 等4H收盘确认后，下一根15m开盘做空
```

上影线比例计算：

```text
整根K线振幅 = 最高价 - 最低价
上影线长度 = 最高价 - max(开盘价, 收盘价)
上影线比例 = 上影线长度 / 整根K线振幅
```

## 6. 仓位规则

账户权益的 5% 作为单笔保证金。

示例：

```text
账户权益 = 1000 USDT
单笔保证金 = 1000 × 5% = 50 USDT
杠杆 = 20x
名义仓位 = 50 × 20 = 1000 USDT
```

这看起来是 20x，但因为只拿账户 5% 做保证金，实际账户总暴露大约是 1倍账户权益。

禁止：

```text
全仓20x
加仓摊平
信号没确认提前进
连续亏损后放大保证金
```

## 7. 止损止盈

20x 近似强平距离约 4.5%。

本策略用：

```text
止损距离 = 强平距离 × 80%
约等于入场价反向 3.6%
止盈 = 0.25R
约等于入场价正向 0.9%
```

做多：

```text
强平价 ≈ 入场价 × (1 - 4.5%)
止损价 ≈ 入场价 × (1 - 3.6%)
止盈价 ≈ 入场价 × (1 + 0.9%)
```

做空：

```text
强平价 ≈ 入场价 × (1 + 4.5%)
止损价 ≈ 入场价 × (1 + 3.6%)
止盈价 ≈ 入场价 × (1 - 0.9%)
```

注意：不同交易所、不同保证金模式、资金费率、维持保证金会导致真实强平价不同。实盘必须以 OKX 下单界面显示的预估强平价为准。

## 8. 当前信号判断流程

每根4H收盘后检查一次。

做多检查：

```text
价格是否贴近唐奇安60下轨？
RSI14 是否 <= 35？
这根4H 是否收阳？
这根4H 收盘是否高于上一根4H收盘？
下影线是否至少占整根K线50%？
ATR14 / 收盘价 是否在 0.6%-6%？
```

做空检查：

```text
价格是否贴近唐奇安60上轨？
RSI14 是否 >= 65？
这根4H 是否收阴？
这根4H 收盘是否低于上一根4H收盘？
上影线是否至少占整根K线50%？
ATR14 / 收盘价 是否在 0.6%-6%？
```

只要有一条不满足，就不交易。

## 9. 执行纪律

这套策略的优势来自少交易和严过滤。

必须遵守：

```text
只在4H收盘后判断
只在下一根15m开盘执行
只用账户5%保证金
止盈止损提前挂好
同一时间只持有一笔
止损后不立刻反手
一天最多开一笔
```

如果信号在4H盘中出现，但收盘前消失，不算信号。

## 10. 风险说明

这套策略的胜率高，但不是低风险策略。

风险点：

```text
20x 下强平距离很近
止盈短，滑点和手续费会明显影响收益
极端插针可能跳过止损
样本只有21笔，不能视为长期稳定盈利证明
当前市场结构变化后，参数可能失效
```

50x 和 100x 的同类回测结果很差：

```text
50x：收益 -37.60%，最大回撤 42.05%，强平 4 次
100x：收益 -73.95%，最大回撤 75.68%，强平 12 次
```

结论：

```text
只保留 20x + 5%保证金版本
不使用 50x / 100x 执行这套策略
```
