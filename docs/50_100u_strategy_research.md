# BTC-USDT-SWAP 单笔 50-100U 策略研究

更新时间：2026-05-29  
账户假设：1000U 本金  
交易品种：OKX BTC-USDT-SWAP 永续  
数据周期：2025-05-29 09:45 -> 2026-05-29 09:45  
数据级别：15m + 4H  
费用假设：单边手续费 0.05%，滑点 1 bps  

> 结论先说：为了把单笔盈利做到 50-100U，不能继续用“摸底摸顶小止盈”模式。当前回测里唯一满足目标且全年、测试段都为正的，是 **4H 趋势突破策略**。它不是高胜率策略，而是低频、低胜率、吃大段趋势的策略。

## 1. 研究目标

目标不是找收益最高的参数，而是找一个值得人工盯盘的执行方案：

```text
1. 允许做多做空
2. 杠杆倍率不限制
3. 1000U 本金下，盈利单平均盈利在 50-100U
4. 最近一年回测为正
5. 后 1/3 测试段也为正
6. 不允许出现强平
7. 回撤不能大到无法执行
```

## 2. 测过的策略族

### A. 摸底摸顶高收益版

规则来源于之前的唐奇安60 + RSI14 + 长影线反转策略，把止盈从 0.25R 拉到 1.5R，并提高单笔保证金。

结果：

```text
高收益_立即入场_1.5R
交易：26
胜率：26.92%
收益：-19.24%
最大回撤：19.24%
平均盈利：37.02U
平均亏损：-23.77U
强平：0
```

结论：不通过。单笔盈利还没稳定到 50U 以上，胜率已经明显下降，整体亏损。

### B. 15m 日内趋势突破

规则：15m 突破前 N 根高低点，同时用 4H EMA 趋势过滤；尝试 20x-100x、不同保证金、不同止盈R和 4-24 小时持仓限制。

结果：

```text
符合“平均盈利50-100U + 全年为正 + 测试段为正 + 无强平”的候选：0
```

结论：不通过。短周期想硬做 50-100U，需要更高杠杆或更大保证金，回撤和强平风险会失控。

### C. 4H 趋势回踩

规则：4H EMA20/60/120 顺势排列，回踩 EMA20 后收回，下一根 15m 入场。

结果：没有找到稳定满足目标的参数。能拉到 50U 以上的版本，全年收益或测试段收益为负。

结论：不作为当前主策略。

### D. 4H 趋势突破

规则：4H 收盘突破过去 40 根 4H 高低点，且方向与 EMA 趋势一致，下一根 15m 入场。

结果：通过筛选，是当前唯一可执行候选。

## 3. 最终候选策略

策略名称：

```text
4H 趋势突破 50-100U 版
```

参数：

```text
本金：1000U
杠杆：8x
单笔保证金：10% = 100U
名义仓位：约 800U
止盈：3.5R
止损：4H ATR14 * 2.2
最长持仓：不强制限时
同一时间：只持有一笔
```

等效替代：

```text
10x 杠杆 + 8% 保证金
```

这两个版本名义仓位都约等于 800U，回测结果基本一致。实际执行优先选 **8x + 10% 保证金**，因为强平距离更远。

## 4. 入场规则

只在 4H 收盘后判断，北京时间：

```text
00:00
04:00
08:00
12:00
16:00
20:00
```

做多条件：

```text
1. 当前4H收盘价 > 过去40根4H最高价
2. 当前4H收盘价 > EMA120
3. EMA20 > EMA60
4. RSI14 >= 52
5. ATR14 / 收盘价 在 0.4% - 5% 之间
6. 下一根15m开盘入场做多
```

做空条件：

```text
1. 当前4H收盘价 < 过去40根4H最低价
2. 当前4H收盘价 < EMA120
3. EMA20 < EMA60
4. RSI14 <= 48
5. ATR14 / 收盘价 在 0.4% - 5% 之间
6. 下一根15m开盘入场做空
```

止损止盈：

```text
做多止损 = 4H收盘价 - ATR14 * 2.2
做空止损 = 4H收盘价 + ATR14 * 2.2
止盈 = 3.5R
```

R 的定义：

```text
做多：R = 入场价 - 止损价
做空：R = 止损价 - 入场价
```

## 6. 持仓时间

这个策略不能强行做成日内策略。实测如果加最长持仓限制，结果会变差：

```text
不限制持仓：+17.01%，平均盈利75.08U
最长24H：-14.93%，平均盈利11.96U
最长48H：-19.11%，平均盈利15.10U
最长72H：-25.40%，平均盈利17.69U
最长336H：+3.10%，测试段为负
```

结论：

```text
这套策略不是一直盯盘的短线单。
正确做法是 4H 收盘后检查信号，入场后挂好止损止盈，然后让它跑。
```

## 8. 执行纪律

必须遵守：

```text
1. 只在4H收盘后判断
2. 只在下一根15m开盘附近执行
3. 同一时间只持有一笔
4. 开仓后立刻挂止损和止盈
5. 不补仓
6. 不因为连续亏损提高保证金
7. 连续亏损4笔后必须暂停复盘
```

不要做：

```text
不要在4H未收盘时提前进
不要用50x/100x硬套这套规则
不要把止盈改小后还叫高收益策略
不要因为胜率低而手动提前平掉盈利单
```

## 9. 当前结论

可以沉淀为候选实盘观察策略，但不建议立刻大仓实盘。

更合理的执行顺序：

```text
第一阶段：模拟盘或极小仓跑 20 笔
第二阶段：确认自己能接受低胜率和长持仓
第三阶段：再按 1000U 本金、100U 保证金执行
```

如果你不能接受连续亏损和长持仓，这套策略不适合你。  
如果你能接受低胜率，且只想等大一点的单笔收益，它比高杠杆摸底版本更合理。
