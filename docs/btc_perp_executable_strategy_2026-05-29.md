## 1. 为什么放弃摸底摸顶和公开视频策略

前面测过几类策略：

```text
1. 摸底摸顶高杠杆：胜率可以做高，但盈亏比差，放大止盈后整体转亏。
2. GitHub / Freqtrade 常见策略：移植到 BTC 单一永续后，全年和样本外都不稳定。
3. 15m 高频突破：交易太碎，手续费和假突破损耗明显。
4. 4H 回踩策略：胜率比突破舒服，但单笔盈利不够，样本外不够硬。
```

这次新增的 `perp_strategy_lab.py` 扫描了 3024 个永续长短双向组合，能过门槛的 36 个几乎都收敛到同一类规则：

```text
4H 唐奇安40突破
+ EMA120/EMA180趋势过滤
+ ADX22趋势强度过滤
+ ATR止损
+ 3R止盈
+ 最长96小时退出
```

这说明真正有用的不是某个神奇指标，而是：只在 BTC 已经走出方向时跟随，不提前猜底猜顶。

## 5. 做多规则

只在 4H 收盘后判断，北京时间：

```text
00:00 / 04:00 / 08:00 / 12:00 / 16:00 / 20:00
```

做多必须全部满足：

```text
1. 当前4H收盘价 > 过去40根4H最高价
2. 当前4H收盘价 > EMA180
3. ADX14 >= 22
4. ATR14 / 当前收盘价在 0.4% 到 6% 之间
5. 当前没有持仓
```

入场：

```text
下一根15m K线开盘做多
例如16:00的4H K线收盘确认，16:00-16:15这根15m开盘可以执行。
```

止损：

```text
止损价 = 4H收盘价 - ATR14 * 2.4
```

止盈：

```text
R = 入场价 - 止损价
止盈价 = 入场价 + 3R
```

## 6. 做空规则

做空必须全部满足：

```text
1. 当前4H收盘价 < 过去40根4H最低价
2. 当前4H收盘价 < EMA180
3. ADX14 >= 22
4. ATR14 / 当前收盘价在 0.4% 到 6% 之间
5. 当前没有持仓
```

入场：

```text
下一根15m K线开盘做空
```

止损：

```text
止损价 = 4H收盘价 + ATR14 * 2.4
```

止盈：

```text
R = 止损价 - 入场价
止盈价 = 入场价 - 3R
```

## 7. 持仓和平仓规则

开仓后立刻挂单：

```text
1. 立刻设置止损
2. 立刻设置3R止盈
3. 最长持仓96小时，到时间还没止盈止损就平仓
4. 同一时间只持有一笔，不加仓，不摊平
```

程序回测里还使用了跟踪止损：

```text
价格先走出有利方向后，用 3 * ATR14 做跟踪止损
达到约1R后允许保本
```

如果你手动执行嫌麻烦，可以先用简化版：

```text
只挂初始止损 + 3R止盈 + 96小时强制平仓
```

但实盘前最好再单独回测“无跟踪止损版”，因为这会改变盈亏分布。

## 10. 执行纪律

这套策略最重要的不是指标，而是纪律：

```text
1. 只看4H收盘，不看未收盘K线冲上冲下。
2. 没突破唐奇安40，不开仓。
3. 开仓后必须马上挂止损。
4. 连亏4笔以内属于历史正常范围，不允许翻倍下注。
5. 连亏5笔后暂停，重新跑最近数据再恢复。
6. 单笔保证金不要超过15%，除非你能接受25%以上权益回撤。
```
